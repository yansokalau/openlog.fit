Built for the set you're about to do

Track anything by the session

Last time, at a glance

Every exercise shows your previous session's weights and reps, so progressive overload is a glance, not a scroll.

Machine taken? Swap it

Keep alternatives for each exercise with their own targets. Switch in one tap and keep the history comparable.

Kilograms or pounds

Install it like an app

OpenLog installs straight from the browser. No app store, no download size to speak of, and it opens full screen and offline from your home screen.

iPhone & iPad

Open openlog.fit in Safari, tap Share, then Add to Home Screen.

Android

Tap Install app on this page, or ⋮ → Install app in Chrome.

Desktop

In Chrome or Edge, click the install icon at the right of the address bar.

Questions

Is OpenLog free?+

Yes. There is no paid tier, no ads and no sign-up.

Where is my training data stored?+

Only in your browser on your device. There is no account, and your log is never uploaded. The one exception is the optional AI plan builder: what you type into it is sent to OpenAI to write your plan, and is not stored.

Does it work offline?+

Yes. After the first visit the whole app is cached, so it opens and logs in a basement gym with no signal.

How do I move my log to a new phone?+

Export a backup file from the menu, send it to the new device, and import it there. Import replaces what was on the new device.

How do I install it on my phone?+

On Android or desktop Chrome, use the Install button. On iPhone, open the site in Safari, tap Share, then Add to Home Screen.
